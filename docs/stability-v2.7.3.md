# v2.7.3 稳定性修复与验收记录

基线是已经发布、已经部署到实验站的 v2.7.2（937888cf）。本轮不覆盖该标签。

## 行为与兼容性

- 日志数字主键保持不变，JSON 新增权威 `id_str`；正文引用另有 `relay_log_id_str`。新前端拒绝不安全的旧数字 ID，同 ID SSE 更新替换旧记录，断线重连补拉，连接异常且页面可见时每 15 秒补查。404 仅表示未找到记录。
- `/api/v1/log/stream?version=2` 增加 `requests` 快照和 `request` 状态事件；旧接口的数据格式不变。状态来自当前进程，以 `trace_id` 关联最终日志，并带进程实例标识。最多保留 256 个摘要、每个模型/渠道名称最多 256 字节；慢订阅者断开后重新获取快照。摘要没有提示词、正文、密钥或逐 Token 数据库写入。
- 渠道详情的操作区固定在滚动内容之外。分组更新在输入校验之后开启事务，所有非提交路径回滚；重试覆盖的 CASE 使用整数列兜底，保留 NULL=继承、0=显式零值。提交后缓存刷新失败使用不同的错误键，避免诱导重复提交；错误关联编号同时进入服务端日志。
- 初始化总预算 120 秒，每次加载最多 30 秒，最多两个并行加载，受连接池容量约束。暂时性故障最多尝试三次；日志记录阶段耗时、连接等待和失败分类。统计全部读取成功后才发布缓存，API Key 额度统计读取失败不会用零替代。
- 明确的 Gemini prompt/candidate 内容阻止和完整 Google 提交失败通知不再作为正常正文。尚未提交下游响应时返回 400，并保留 `content_filter` 信号；已输出时发送协议终态错误，不重发请求、不计渠道熔断。用量保持上游报告值。
- 通知识别只检查回答文本，完整匹配已知通知；不检查提示词、思考或工具结果。正常解释、引用、代码不因出现关键词就判失败。可能匹配通知的流式开头最多暂存 4 KiB 的输出帧和 1 秒；超过边界即释放，后续异常只终止/记录，不回退重试。自由文本的疑似语义截断没有引入 AI 判别或自动失败。
- `User location is not supported for the API use` 属于上游渠道可用性错误，未输出时可换渠道。

## 探测及调度缺陷

协议应用使用 JSON 序列化并刷新运行时缓存；前端同时刷新正确的渠道和能力查询键。按 Key 同步成功空目录沿用旧目录，不删除仍被保留的模型。媒体路径应用下游模型白名单；分组测活按模型选 Key。

协议探测拒绝 HTTP 200 错误包、HTML 和空体；暂时性故障不能被关键词改成确定的不支持。能力探测沿用已验证协议，解析实际响应信封内的结构化输出，搜索使用原生工具；应用时防止互斥协议混入。探测摘要脱敏、排队可取消、历史保存失败不清空结果，前端可停止并在关闭时取消请求。

069 字段映射已修正，071 仅校正可验证的旧迁移数据；人工/探测结论不覆盖。粘性缓存记录实际模型以便按真实模型逃生；首字耗时按本次尝试计量；AI 分组追问持有完整服务占用租约。MiMo 隐藏不生效的协议选择。

## 验证与发布门槛

本地已运行后端 `internal/...`，以及前端 lint、i18n、unit、integration-ui、airoute 和 webpack 生产构建。独立复现已经转为正式回归，覆盖模型权限、协议假成功、Responses 能力、结构化输出、脱敏、取消和粘性别名等。

PostgreSQL 集成测试使用 `OCTOPUS_TEST_POSTGRES_DSN`，只允许本机地址，并创建/清理独立 schema。CI 提供临时 PostgreSQL 17 服务；测试包含真实迁移、全 NULL/全数值/混合覆盖、事务回滚和连接归还。没有配置该测试库的本地环境会明确 skip，不作为 PostgreSQL 通过证据。

本地真实浏览器已验证：长渠道详情在桌面和 390×700 视口下编辑/删除可点击，编辑页保存/取消可聚焦；渠道改名实际落库，分组更新返回 200。实际 HTTP/SSE 测试记录了 received → waiting → attempt → streaming → completed → recorded，并用 trace_id 关联最终日志。正常流返回 200，分片 Google 通知返回 400/content_filter，详情保留输入 12、输出 7 token。浏览器可以读取大整数 ID 对应详情，敏感凭证已脱敏。

生产 jsoniter 构建标签下的转发、模型序列化、迁移、分组及 handler 回归已通过。PostgreSQL CI 与实验站验收仍是独立发布门槛。实验站为 `https://octopus-d3ax.onrender.com/`；生产环境不因构建成功自动升级。正式镜像需记录新标签和固定 digest，实验站验收后再评估生产部署。
